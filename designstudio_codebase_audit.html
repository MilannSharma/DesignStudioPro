End-to-end analysis across 15 source files · Fabric.js 7 · React 19 · Vite 6

CRITICALUX-Breaking Issues
Text tool uses window.confirm() / window.prompt() — blocks browser thread, feels ancient, breaks flow entirely
Replace with inline floating modal or inline options in FloatingToolbar
Polygon & Star tools also use window.prompt() for input — same problem
Use a floating popover positioned near cursor on mouse:down
Callout direction uses window.prompt() — should be a mini toolbar that appears on draw
History (undo/redo) blocks on loadFromJSON — no loading state shown, canvas flickers on complex pages
Debounce saveHistory; add micro-spinner or optimistic UI during load
Object boundary enforcement clips objects while dragging — feels like hitting a wall instead of smooth stopping
Apply clamping on mouse:up only, not on mouse:move for better feel
HIGHLogic & State Bugs
fitProjectToScreen, centerProject, zoomTo100 are empty stubs in the store — overridden by CanvasArea but never wired back; direct store calls fail silently
Undo/Redo saves history on EVERY object:added — including shape draw preview objects (isDrawingPreview guard is partial)
All intermediary drawing objects should be fully excluded from history
Page switching is synchronous — setCurrentPage saves current page first, but if canvas is mid-draw, partial state gets saved
Copy/Paste (Ctrl+V) uses top-level await import('fabric') inside keydown handler — can cause timing issues in Firefox
Smart guides display via smartGuidesRef but the render overlay is never actually drawn — guides are computed but invisible to the user
Spiral and Callout don't respect document color scheme — hardcoded colors don't follow the active fill/stroke from PropertiesPanel
Pen tool path anchors isAnchor flag is not excluded from export — anchors appear in exported SVG/JSON
LayersPanel only re-renders on selectedObjects change — adding/removing objects on canvas doesn't auto-refresh the panel
MEDIUMMinor Bugs & Polish Issues
Ruler mouse position readout lags — mousePos state update on every mouse:move triggers full React re-render of CanvasArea
Use ref + direct DOM manipulation for ruler cursor lines
Guide lines dragged off-canvas are not removed — they persist invisibly and accumulate in state
Zoom via scroll uses 0.999 ** delta — extremely slow on trackpads with deltaY=3; should normalize delta
Context menu appears on right-click even when in text editing mode — should be suppressed
ShapeLibrary component imported in App.tsx but not visible in the file's JSX render — likely dead import
Export to PDF uses jsPDF rasterization — not vector; complex layouts lose sharpness at print resolution
PropertiesPanel unit conversion (mm/cm/inch) doesn't recalculate on unit change — existing values stay in old unit

PERFORMANCEArchitecture & Performance Issues
CanvasArea is a 1400-line monolith — mouse:down, mouse:move, mouse:up all in one useEffect; split into tool-specific handlers using a strategy pattern
PropertiesPanel is a 900+ line monolith — extract TextProperties, ShapeProperties, ImageProperties, AlignmentBar into separate components
setMousePos on every mouse:move causes full React re-render 60fps — move ruler rendering to a canvas overlay or use useRef + direct DOM
History stores full JSON strings on every change — on a complex canvas this is MBs of data per action; use JSON diff patches (e.g. fast-json-patch) instead
All fonts are eagerly preloaded in a hidden div on App mount — this fires hundreds of Google Fonts requests on startup; use on-demand font loading only when selected
CODE QUALITYCode Quality Improvements
Multiple cn() helpers defined identically in 6+ files — extract to src/lib/utils.ts and import
CUSTOM_PROPS array duplicated in useStore.ts and TopBar.tsx — single source of truth needed
All tool logic (draw, pan, pen, eyedropper) inside CanvasArea — implement a Tool interface with onMouseDown/Move/Up methods per tool
No error boundaries — a crash in any panel kills the whole UI; wrap major panels in ErrorBoundary
No keyboard shortcut registry — shortcuts are scattered across App.tsx and CanvasArea; centralize in a useKeyboardShortcuts hook with a cheatsheet panel
